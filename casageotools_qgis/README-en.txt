To install this plugin, open QGIS and navigate to "Plugins" > "Manage and
Install Plugins..." > "Install from ZIP" and select the plugin ZIP file. Then
click on "Install Plugin" and confirm that you received this plugin from a
trusted source.

To use the full capabilities of this plugin, you also need to install some
required Python dependencies. Navigate to "Plugins" > "casaGeoTools" and click
on "Install Python dependencies".
