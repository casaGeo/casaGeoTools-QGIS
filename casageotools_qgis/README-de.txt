Thank you for choosing casaGeoTools for QGIS.

Sie können diese Erweiterung direkt über die QGIS-Oberfläche installieren.
Öffnen Sie dazu das Menü unter "Erweiterungen" > "Erweiterungen verwalten und
installieren..." > "Aus ZIP installieren" und wählen Sie die Plugin-ZIP-Datei
aus. Klicken Sie anschließend auf "Erweiterung installieren" und bestätigen Sie,
dass sie die Plugin-ZIP-Datei aus einer vertrauenswürdigen Quelle erhalten
haben.

Damit Sie die Erweiterung vollständig nutzen können, müssen Sie zusätzlich
einige benötigte Python-Pakete installieren. Klicken Sie dazu auf
"Erweiterungen" > "casaGeoTools" > "Python-Abhängigkeiten installieren".
