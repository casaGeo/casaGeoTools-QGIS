# casaGeoTools QGIS Plugin

A Python connector for the HERE Location Platform – designed for geocoding,
routing, and isoline analytics.

This plugin respects the QGIS proxy settings.


## Python Dependencies

This extension requires the `casaGeoTools` package to be installed in your QGIS
Python environment. Core functionality will be unavailable otherwise. You can
install it from the QGIS interface by going to `Plugins > casaGeoTools > Install
Python dependencies`. See the installation instructions in the plugin
documentation for more details.
